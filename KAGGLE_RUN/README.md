For every notebook: **Add Input → RSNA Knee Abnormality Detection** (the competition), pick
the accelerator and Internet setting below, then **Save Version → Save & Run All**. Wait for
the saved version to succeed before attaching its output anywhere. Keep the same Kaggle
environment (Settings → Environment → pin) for every training and submission run.

## Step 4b — three training sessions (GPU **T4 x2**, Internet ON)
Kaggle bills GPU quota per session hour and its T4 sessions have two GPUs, so each session
trains two jobs side by side, one process per GPU, with the exact single-GPU recipe.
- `04_session_A_reader_f0_f1` — ConvNeXt reader folds 0 and 1
- `04_session_B_reader_f2_f3` — ConvNeXt reader folds 2 and 3
- `04_session_C_reader_f4_slot_rad` — reader fold 4 on GPU 0; DINOv2 slot folds 0–4 then the
  RadImageNet heads on GPU 1

The preflight projects ~2.5 h per reader fold, so each session takes roughly 2.5–3 h of
quota (about 8–9 h for all three, instead of ~16 h one fold per session). Sessions are
independent; run them one after another or as many at once as Kaggle allows. Each prints the
label readers, the recipe and every epoch's losses every two minutes, writes one folder per
family (`reader_convnext/`, `slot_dinov2/`, `radimagenet/`), and fails loudly if a job fails.
Gold studies train at weight 3, so their printed audit says IN-SAMPLE.

## Step 5 — submission (GPU T4, **Internet OFF**)
`05_submit.ipynb`. Attach: the competition, the `knee-wheelhouse` dataset (offline packages; do

Early check: after session A, run this with only that output attached.

## If something stops
- A session was interrupted: attach its saved output to a fresh run of the same session and
  set `RESUME_DIR` (third cell) to that output folder; folds with `fold_N.pt` and
  `last_fold_N.pt` resume at their next epoch, finished folds are skipped only if you remove
  them from `GPU_JOBS`.
- Out of GPU memory: lower `BATCH` and raise `ACCUM_STEPS` for that preset in `train_config.py`,
  rebuild, re-import.
- The session log prints every label reader it found. Check it lists the four public tables,
  `extra_labels_sol_v2.csv`, `extra_labels_sonnet_legacy.csv` and the Flash-Lite `.jsonl` file.
- `optional/single_runs/` holds one-fold-per-notebook versions of every job (single GPU), for
  reruns. `optional/01_labels.ipynb` regenerates labels through Kaggle's model service; not
  needed.
- CoAtNet-RMLP-2 @384 is not part of the plan: it ran out of memory on a T4 in the preflight.
